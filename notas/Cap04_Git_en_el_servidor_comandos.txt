CAPÍTULO 4. GIT EN EL SERVIDOR
==============================

Notas de comandos del capítulo (resumen rápido para consulta).


[4.1 Los protocolos]
  git clone /srv/git/proyecto.git
  git clone file:///srv/git/proyecto.git
  git clone https://github.com/usuario/proyecto.git
  git clone ssh://usuario@servidor/proyecto.git
  git clone usuario@servidor:proyecto.git

[4.2 Configurar Git en un servidor]
  git clone --bare mi_proyecto mi_proyecto.git
  scp -r mi_proyecto.git usuario@servidor:/srv/git
  git init --bare --shared

[4.3 Generar una clave SSH]
  ssh-keygen -t ed25519 -C "tu_correo@ejemplo.com"
  cat ~/.ssh/id_ed25519.pub

[4.5 Demonio Git, HTTP inteligente y GitWeb]
  git instaweb --httpd=webrick

Fuente: Chacon, S., & Straub, B. (2014). Pro Git. https://git-scm.com/book/es/v2
